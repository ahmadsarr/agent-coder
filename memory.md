# Plan to create a Python library for basic math operations

## Project Structure
- `math_lib/` (package)
    - `__init__.py`
    - `operations.py` (contains add, subtract, multiply, divide)
- `tests/` (test suite)
    - `test_operations.py`
- `setup.py` (for installation)
- `README.md`

## Steps
1. Create the directory structure.
2. Implement math operations in `math_lib/operations.py`.
3. Initialize the package with `math_lib/__init__.py`.
4. Write unit tests in `tests/test_operations.py`.
5. Create `setup.py` for packaging.
6. Verify everything works by running the tests.
